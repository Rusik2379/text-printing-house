## Расхождения с новым архивом

1. В main пока нет отдельных страниц и калькуляторов для 44 услуг из 55. Визитки рассчитываются в общем окне; 11 услуг наклеек имеют собственные страницы. Тексты каталога иногда говорят об онлайн-калькуляторе для услуг, где доступен только запрос. При расширении стоит согласовать эти обещания с фактическими возможностями.
2. В технических данных архива заполнены короткие фиксированные параметры для всех 55 услуг. В текущем `company-content.json` эти массивы пусты. Остальные подробные требования совпадают, кроме трёх массивов с удалёнными упоминаниями стороннего бренда. Всего обнаружено 58 различающихся полей. Эти дополнения проанализированы, но пока не заменяли видимое содержание страниц.
3. В архиве есть видео демонстрации 3D-стикерпаков, которого нет в текущем интерфейсе. Его можно использовать при отдельной доработке страницы этой услуги.
4. В клиентской версии описан PDF расчёта; наша корзина выдаёт текстовый расчёт и подготовленное письмо. Поэтому обещание PDF не перенесено в SEO главной.
5. Исправление `quantityUnit()` от 8 октября относится к калькуляторам клиентского архива. Наши калькуляторы устроены иначе; копирование его `app.js` поверх нашего сломало бы существующий интерфейс.
6. Клиентский архив содержит четыре страницы решений для разных аудиторий и шесть страниц категорий. Это дополнительный материал для будущих страниц; они не создавались автоматически.
7. Технический PDF содержит 51 страницу, включая внутренние вопросы на согласование и ссылки на источники в конце. Вылеты 4 мм подтверждены для листовок; другие размеры необходимо брать из требований конкретной услуги. Этот документ нельзя без редакторской проверки считать полностью готовой публичной инструкцией.
