# UV-печать и резка

Оформление — текущая главная и общий шаблон страниц услуг. Контент,
иллюстрации и формулы перенесены из «Еговерсия2». Последний main,
интегрированный перед работой, — `666f52d`.

| Услуга | Книга расчёта | Минимальный чек |
|---|---|---:|
| Прямая UV-печать / таблички | Прямая УФ печать и Таблички | 800 ₽ |
| Плоттерная резка | Плоттерная резка | 600 ₽ |
| Лазерная резка CO₂ | Лазерная резка СО2 | 800 ₽ |
| Лазерная гравировка CO₂ | Лазерная гравировка СО2 | 800 ₽ |
| Брелоки / гардеробные номерки | Брелоки | 1 000 ₽ |
| Шильды / UV-печать на металле | Шильдики | 1 000 ₽ |

Минимум применяется один раз на книгу в общей корзине. Плоттерная резка
разделяет группу с готовыми наклейками на авто и стекло в широком формате.
При округлении стоимости небольшой работы до нуля минимальный чек
сохраняется в корзине, PDF и запросе; нерассчитанные позиции его не создают.
Валюта в интерфейсе и корзине округляется до копеек; внутренние формулы
сохраняют исходную точность. Ориентир срока — итог / 7 000 ₽ с округлением
вверх, минимум один рабочий день после полного согласования макета.

`uv-services.js` содержит маршруты и ограничения, `uv-pricing-data.js` —
исходные расчётные ячейки. `uv-pricing.js` использует существующий безопасный
Excel-вычислитель, добавляет проверку ввода и зависимых опций. Формулы
разбираются как данные; `eval` и `Function` не используются.

Прямая печать и таблички: 50×50–400×600 мм, до 100 изделий. Плоттер:
200×200–600×2000 мм с поворотом. Лазерная резка и гравировка: 900×600 мм
с поворотом. Шильды и металл: 600×400 мм с поворотом. Брелоки и номерки:
20–120 мм по каждой стороне. Материал определяет допустимую толщину и
нанесение; лак доступен только с UV. На металле исключён пластик,
у номерков зафиксирован вариант без фурнитуры.

Длина лазерного реза и контурной гравировки в источнике оценивается по
периметру габаритов. Страница явно показывает этот ориентир: точные
контуры проверяют по макету. Материал для лазерной резки не включён в цену
работы. Эффект лака, крепления и нестандартные изделия согласуются отдельно.

`uv-content.json` хранит индивидуальные тексты, FAQ, углублённые требования
и ссылки на существующие статьи. Редакторский `expert` из источника не
публикуется, служебные оговорки адаптированы в условия для заказчика.
`uv-sharing.js` сохраняет выбранные параметры в тексте/URL;
`uv-print-cut.js` подключает форму, макеты, корзину и индивидуальный запрос.

Пересборка:

```sh
python scripts/build-uv-pages.py
python scripts/build-seo.py
python scripts/version-resources.py
node --test tests/uv-pricing.test.mjs tests/uv-sharing.test.mjs
node scripts/check-pages.mjs
node scripts/check-seo.mjs
```

11 224 независимых ожидаемых случая получены вычислителем исходных книг.
Браузерная проверка `scripts/check-uv-browser.mjs` использует Playwright
(`PLAYWRIGHT_MODULE`, `BROWSER_CHANNEL`, `UV_TEST_URL`, `UV_SCREENSHOTS`).
Она проверяет все девять услуг, параметры, сравнение тиражей, файл, скачивание,
копирование, редактирование корзины, FAQ, мобильную вёрстку и префиксы адресов.
