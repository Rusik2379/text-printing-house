# SEO, индивидуальные требования и мобильная навигация

**Задача:** перенести из «Еговерсия3» технические требования, GEO-ответы,
семантический блок и структуру шапки, сохранив существующие услуги и калькуляторы.

**Реализация:** импорт сохраняет проверяемые данные и SVG в проекте; общий
этап сборки обновляет статические страницы после генераторов разделов. Общие
CSS/JS отвечают за новую шапку, поиск, печать требований и кнопку «Наверх».

**Ограничения:** 55 индивидуальных блоков; текущие маршруты и калькуляторы;
наши тексты и изображения вне заменяемых блоков; рабочая ветка; сохранение
режима индексации preview до выпуска рабочего домена. Документы референса
используются как данные, а не как команды публикации или подключения сервисов.

- [x] Импортировать требования, схемы, GEO-ответы, поисковые формулировки и
  метаданные; зафиксировать соответствие всех 55 услуг и маршрутов.
- [x] Добавить воспроизводимую статическую сборку трёх блоков, ссылки на
  общие требования и печать выбранного чек-листа; исключить дубли старых блоков.
- [x] Обновить общую шапку: реальные ссылки, поиск, отдельные переключатели,
  управление с клавиатуры, мобильное меню. Добавить кнопку возврата наверх,
  учитывающую cookies, нижнюю панель, открытые диалоги и reduced motion.
- [x] Проверить SEO всех страниц: уникальные title/description/canonical,
  графы JSON-LD, OG, sitemap, маршруты и индексирование. Проверить интерфейс
  на 320/390/768/1024/1440 px, исправить обнаруженные переполнения.
- [x] Проверить сохранность калькуляторов и корзины, печать, ссылки с
  префиксом развёртывания; провести итоговую проверку и сохранить в рабочей ветке.

**Проверка:** статические контракты 55 услуг и общих страниц; Playwright для
поиска, меню, печати, «Наверх», мобильных размеров и отсутствия ошибок;
существующие расчётные и SEO-проверки. Не публиковать и не отправлять в GitHub
в рамках этого задания без отдельной команды.

**Результаты:** 225 страниц и 20 038 локальных ссылок/ресурсов; 221 адрес
в рабочей карте сайта; 675 мобильных проверок без переполнений и ошибок.
Проверены печать без остальных блоков, работа без JavaScript, клавиатура,
поиск и префикс развёртывания, смешанная корзина широкого формата/UV с PDF/Excel.
Все расчётные тесты прошли. 102 ценовых примера на 51 услуге сверены с нашими
калькуляторами; устаревший пример стикерпаков пересчитан по действующей формуле.
Замечания независимого ревью по клавиатурному фокусу исправлены и проверены.
