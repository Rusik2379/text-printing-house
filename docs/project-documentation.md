# Проектная документация

Раздел включает обзор `/proektnaya-dokumentatsiya/` и семь страниц услуг:

| ID | Услуга | Адрес внутри раздела |
| --- | --- | --- |
| 2.1 | Инженерная печать | `inzhenernaya-pechat/` |
| 2.2 | Брошюровка проектной документации | `broshyurovka-proektnoy-dokumentatsii/` |
| 2.3 | Фальцовка чертежей по ГОСТ | `falcovka-chertezhey/` |
| 2.4 | Сканирование чертежей | `skanirovanie-chertezhey/` |
| 2.5 | Копирование чертежей | `kopirovanie-chertezhey/` |
| 2.6 | Печать дизайн-проектов | `pechat-dizayn-proektov/` |
| 2.7 | Печать лекал и выкроек | `pechat-lekal-i-vykroek/` |

Источники: `TEKST_HTML_FINAL.zip`, исходные книги заказчика и технические профили от 07.10.2026. SHA-256 архива и версия требований записаны в `project-content.json`. Импорт читает JSON-литералы, не исполняет код архива. Используется подробный `technical-data.js`, включая формат файла, критичные условия, ошибки и производственную проверку. Старый `technical-content.json` поддерживается для совместимости.

Оформление использует шаблон и CSS копицентра: те же первые экраны, шрифты, отступы, карточки услуг, примеры цены, варианты, этапы, подготовка файлов и FAQ. У проектного раздела нет отдельного оформления первого экрана или карточек. `project.css` добавляет только раскладку групп листов, длинных селекторов и состояние пункта меню. Изображения отделены от HTML-текста. Все 21 примера цены рассчитаны по исходным формулам. Подробные требования находятся в четырёх раскрывающихся карточках с общей анимацией FAQ. В услугах для бумажных оригиналов загрузка файла остаётся необязательной; подписи объясняют передачу оригиналов в студию.

Инженерная печать и копирование рассчитывают до 20 групп листов; дизайн-проекты — до пяти. Этот набор параметров задан исходными книгами, а внешний вид калькулятора использует оформление копицентра. Основная группа показана в трёх столбцах с кнопками формата, цветности и количества. Цены рядом с количеством показывают стоимость всего заказа, включая остальные группы и обработку. Удлинённые форматы доступны в отдельном списке. Кнопка «Добавить другой формат» создаёт компактную дополнительную группу. Группы можно дублировать и удалять. Количество листов указывается суммарно на весь заказ; число альбомов задаёт количество переплётов. Изменение цвета не сбрасывает введённые количества. Фальцовка и сборка раскрываются отдельной кнопкой и входят в общий расчёт; сворачивание сохраняет параметры. При восстановлении ссылки или редактировании выбранная обработка сразу видна. Общая линия над списками FAQ удалена из базового CSS, рамки отдельных карточек сохранены.

Тарифы и округления сохранены из исходных формул. Для проектной брошюровки применяется коэффициент 1,15; сканирование ограничено A3; выкройки — 841 × 18 000 мм. Фальцовку A4 с ценой 0 ₽ нельзя добавить в корзину, но объяснение можно сохранить. Срок — один рабочий день на 25 000 ₽ с округлением вверх после согласования.

Все семь форм поддерживают копирование параметров и ссылки, TXT, комментарий, макет и редактирование позиции корзины. Новое добавление создаёт отдельную позицию и не открывает диалог. Общая корзина позволяет скачать PDF с логотипом, параметрами и ценами. Файлы сохраняются в браузере и прикрепляются к письму вручную.

Сборка: `python scripts/build-company-pages.py`. Она также обновляет SEO и версии ресурсов. Отдельный генератор — `scripts/build-project-pages.py`, импорт — `scripts/import-project-archive.py`.

Проверки:

```powershell
node tests/project-pricing.test.mjs
node tests/cart-pdf.test.mjs
node scripts/check-pages.mjs
node scripts/check-seo.mjs
```

Для дополнительной проверки форм без браузера:

```powershell
npm install --no-save --package-lock=false --ignore-scripts jsdom
node tests/project-ui.test.mjs
```

DOM-тест исполняет локальные скрипты сайта без сетевых ресурсов. Проверяются все услуги, совпадение структуры общих компонентов с копицентром, общая корзина, редактирование, восстановление ссылок, дублирование независимых групп, лимиты строк, недопустимые количества и полный технический текст. Хранилище реального браузера не используется. Этот тест не проверяет визуальную раскладку.
