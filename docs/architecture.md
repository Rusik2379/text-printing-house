# Архитектура

Приложение использует готовые HTML-страницы и сервер Node.js 24 без внешних
зависимостей в runtime. `npm ci` устанавливает только инструменты разработки.

## Данные и расчёты

Модули `*-services.js` описывают услуги и доступные параметры. `*-pricing-data.js`
содержат тарифные снимки, `*-pricing.js` и `copycenter-engine.js` рассчитывают цены.
Они используются и браузером, и серверным модулем `.server/quotation.mjs`.
Независимые примеры в `tests/` проверяют исходные формулы и пограничные значения.

Тарифные переопределения из админки хранятся в приватном каталоге данных, а не в
репозитории. Изменение цен требует проверки калькуляторов и связанных примеров.

## Интерфейс

`app.js` управляет общими меню, диалогами и корзиной. Контроллеры разделов
`copycenter.js`, `project.js`, `leaflet-ui.js`, `stickerpacks.js`,
`wide-format.js` и `uv-ui.js` используют общую корзину. `cart-extras.js`
обслуживает помощь с макетом и доставку. PDF, Excel и файлы вынесены в отдельные
модули. `site-geo.js` отвечает за сохранённый населённый пункт, `site-search.js`
— за поиск. Крупные географические индексы загружаются по необходимости.

Корневые пути JS/CSS сохраняют совместимость с уже опубликованными страницами.
Стили разделены по общим компонентам и разделам. Динамические классы должны
учитываться при проверке неиспользуемого CSS; отчёт `audit:unused` — список
кандидатов, а не основание для слепого удаления.

## Содержимое и адреса

HTML содержит основной контент и ссылки без выполнения JavaScript. На сайте
1 034 страницы: 807 статей входят в это число. Sitemap содержит 1 029 индексируемых
URL. Адреса, canonical, заголовки и содержимое при очистке не менялись.
После изменения CSS/JS запускайте `npm run assets:version`.

Для новой страницы обновляйте sitemap и поисковый индекс через
`node scripts/rebuild-search-index.mjs`. Эта команда пересобирает текстовый индекс;
статический географический справочник имеет собственный источник и хранится отдельно.
Старые одноразовые импортёры не являются частью обычной сборки.

## Сервер и данные

`server.mjs` объединяет модули `.server/`: каталог и тарифы, HTTP API,
авторизацию, заявки, уведомления и публичные ответы. Каталог `ADMIN_DATA_DIR`
обязан находиться вне публичного корня. В Docker это постоянный том `/data`.
В Git и Docker-контекст не попадают рабочие пароли, `.env`, заказы и макеты.

`npm run build` формирует `.build/site`: только публичные файлы, сервер и
инструмент первичной настройки админки. Тесты, исходные JSON контента,
документация и инструменты разработки в рабочий пакет не копируются.

## Проверки и размещение

`npm run check` проверяет код, статические страницы и SEO, выполняет тесты,
собирает приложение и обходит все адреса sitemap. Runtime-проверка использует
временный каталог и отключённый шлюз уведомлений.

Монитор `infrastructure/indexnow/` работает отдельно и отправляет только
содержательные изменения. Его ключ и состояние переносятся отдельно. Внешний
Nginx Proxy Manager обслуживает HTTPS и часть прямых редиректов старых URL.
Инструкция размещения: [deploy/README.md](../deploy/README.md).
