# SEO и GEO из клиентского референса

Данные обновлены 10 октября 2026 из «Еговерсия3». `seo-content.json` хранит метаданные 232 исходных страниц, данные организации, поисковые формулировки 55 услуг и исправления для наших маршрутов. В нашем сайте 225 страниц, включая отдельный каталог наклеек и стикеров.

`service-enrichment.json` содержит индивидуальные требования, SVG-схемы, пять GEO-ответов и семантические формулировки для каждой из 55 услуг. Блоки записаны в статический HTML. Существующие тексты, изображения и калькуляторы вне заменяемых блоков сохраняются. Общая шапка, мобильное меню, поиск, печать чек-листов и «Наверх» используют `site-chrome.js/css` и `service-enrichment.css`.

## Сборка

Старый импорт ZIP остаётся доступен:

```powershell
python scripts/import-seo-archive.py 'C:\Users\rusik\Downloads\Telegram Desktop\TEKST_HTML_FINAL.zip' --imported 2026-10-08
```

Импорт использует `lxml` для чтения HTML. JavaScript из ZIP не исполняется. Обычная сборка SEO работает на стандартной библиотеке Python:

```powershell
python scripts/build-seo.py
python scripts/version-resources.py
node scripts/check-pages.mjs
node scripts/check-seo.mjs
node tests/service-enrichment.test.mjs
node tests/service-geo-prices.test.mjs
```

`build-company-pages.py` и `build-wide-format-pages.py` применяют общую сборку после генерации страниц. В `build-company-pages.py` также входят генераторы копицентра, проектов, листовой полиграфии и UV. Повторная сборка не дублирует новые блоки. Если нужен определённый Node.js для генераторов, задайте `NODE_BINARY` и добавьте его каталог в `PATH`.

При обновлении «Еговерсия3» сначала запустите референс локально, например на порту 4188, затем экспортируйте проверенные требования и диаграммы. Для экспорта нужен Playwright; путь к модулю можно задать через `PLAYWRIGHT_MODULE`, браузер — через `BROWSER_CHANNEL`.

```powershell
node scripts/export-service-reference.mjs http://127.0.0.1:4188/ reference-data.json
python scripts/import-service-enrichment.py '../../Еговерсия3' --rendered-data reference-data.json
node scripts/refresh-geo-prices.mjs
python scripts/build-seo.py
python scripts/version-resources.py
```

Документы референса используются как контент, без выполнения команд публикации и подключения внешних сервисов. Для обычной сборки папка референса не требуется.

Примеры цен сверены для одинаковых конфигураций с нашими калькуляторами: 102 проверки на 51 услуге. В четырёх услугах референс не содержит фиксированного ценового примера. У стикерпаков формула нашего сайта отличается от примера референса: блок «Сколько стоит» пересчитан через `refresh-geo-prices.mjs`. После изменения тарифов повторите этот шаг и проверки.

## Что перенесено

- Уникальные Title и description; Open Graph с изображениями, которые уже есть в нашем проекте.
- Абсолютные canonical для `https://text-print.ru/`, согласованные с текущими адресами страниц.
- Один JSON-LD граф: LocalBusiness, Service для услуги или CollectionPage с её собственными услугами для раздела, BreadcrumbList, Article для статьи и FAQPage из видимых вопросов и ответов. У сущностей нет повторных идентификаторов; Service содержит город, регион доставки и сведения о калькуляторе и получении заказа.
- `sitemap.xml` с 221 существующим адресом рабочего сайта. Четыре служебные страницы исключены; параметры калькулятора не попадают в карту.
- `robots.txt` и единый режим индексации.

Переезды `/company/` → `/company/about/`, контактов, доставки, требований и 150 статей учтены в `scripts/site_seo.py`. Обзор `/company/` получает собственные метаданные. Три удалённые страницы не возвращаются. Семантические формулировки используются в видимом блоке условий заказа, без тега `keywords`.

В нескольких исходных description текст обрывался; для оплаты, вопросов и оформления заказа используются полные формулировки. На главной убрано обещание PDF, которого текущая корзина не создаёт. FAQ разметка строится из существующих вопросов и ответов, включая все 80 вопросов общей страницы. Оценки организации в структурированные данные не добавляются.

## Индексация и публикация

В `seo-config.json` сейчас `preview`: все страницы имеют `noindex, nofollow`, а `robots.txt` не объявляет карту. Это режим локальной разработки и демонстрационной копии на GitHub Pages. Карта при этом уже подготовлена для рабочего домена.

Перед выпуском на `https://text-print.ru/`:

```powershell
python scripts/build-seo.py --mode production
python scripts/version-resources.py
node scripts/check-pages.mjs
node scripts/check-seo.mjs
```

Режим сохраняется в `seo-config.json`: последующая генерация страниц его не сбрасывает. В `production` 221 страница получает `index,follow`, четыре служебные страницы — `noindex,follow`; `robots.txt` объявляет карту рабочего домена. Для возврата к демонстрационной копии: `python scripts/build-seo.py --mode preview`.

Проверка контролирует уникальность title, description и canonical, один h1, отсутствие повторных метатегов и идентификаторов JSON-LD, наличие изображений, реальные адреса хлебных крошек и карты, типы разметки и режим индексации. Отправка сайта поисковикам и подключение кабинетов вебмастеров не выполняются этой сборкой.
