# SEO из клиентского архива

Данные импортированы 8 октября 2026 из `TEKST_HTML_FINAL.zip`. Содержимое сайта и его оформление сохраняются. `seo-content.json` хранит исходные метаданные 232 страниц, данные организации, поисковые формулировки для 55 услуг и отдельные исправления для наших маршрутов.

## Сборка

При обновлении архива:

```powershell
python scripts/import-seo-archive.py 'C:\Users\rusik\Downloads\Telegram Desktop\TEKST_HTML_FINAL.zip' --imported 2026-10-08
```

Импорт использует `lxml` для чтения HTML. JavaScript из ZIP не исполняется. Обычная сборка SEO работает на стандартной библиотеке Python:

```powershell
python scripts/build-seo.py
node scripts/check-seo.mjs
```

`python scripts/build-company-pages.py` также применяет SEO после генерации страниц. Изменения сохраняются при последующих сборках. Метаданные записаны непосредственно в HTML, поэтому не зависят от выполнения JavaScript.

## Что перенесено

- Уникальные Title и description; Open Graph с изображениями, которые уже есть в нашем проекте.
- Абсолютные canonical для `https://text-print.ru/`, согласованные с текущими адресами страниц.
- Один JSON-LD граф на страницу: LocalBusiness, тип страницы или Service, BreadcrumbList, Article для статей и FAQPage для фактических вопросов на странице.
- `sitemap.xml` с 171 существующим адресом рабочего сайта. Четыре служебные страницы исключены; параметры калькулятора не попадают в карту.
- `robots.txt` и единый режим индексации.

Переезды `/company/` → `/company/about/`, контактов, доставки, требований и 150 статей учтены в `scripts/site_seo.py`. Обзор `/company/` получает собственные метаданные. Три удалённые страницы не возвращаются. Поисковые формулировки сохранены как источник для дальнейшего наполнения услуг, а не как устаревший тег `keywords`.

В нескольких исходных description текст обрывался; для оплаты, вопросов и оформления заказа используются полные формулировки. На главной убрано обещание PDF, которого текущая корзина не создаёт. FAQ разметка строится из существующих вопросов и ответов, включая все 80 вопросов общей страницы. Оценки организации в структурированные данные не добавляются.

## Индексация и публикация

В `seo-config.json` сейчас `preview`: все страницы имеют `noindex, nofollow`, а `robots.txt` не объявляет карту. Это режим локальной разработки и демонстрационной копии на GitHub Pages. Карта при этом уже подготовлена для рабочего домена.

Перед выпуском на `https://text-print.ru/`:

```powershell
python scripts/build-seo.py --mode production
node scripts/check-pages.mjs
node scripts/check-seo.mjs
```

Режим сохраняется в `seo-config.json`: последующая генерация страниц его не сбрасывает. В `production` 171 страница получает `index,follow`, четыре служебные страницы — `noindex,follow`; `robots.txt` объявляет карту рабочего домена. Для возврата к демонстрационной копии: `python scripts/build-seo.py --mode preview`.

Проверка контролирует уникальность Title и canonical, отсутствие повторных метатегов, наличие изображений, реальные адреса хлебных крошек и карты, типы разметки и режим индексации. Отправка сайта поисковикам и подключение кабинетов вебмастеров не выполняются этой сборкой.
