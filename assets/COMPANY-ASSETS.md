# Страницы компании

Четыре иллюстрации предоставлены пользователем в каталоге `сайт/раздел услуги/компания`:

| Файл сайта | Исходник |
| --- | --- |
| company-about.webp | О_нас1.png |
| company-contacts.webp | Контакты1.png |
| company-delivery.webp | Доставка1.png |
| company-requirements.webp | Технические_требования1.png |

Сохранены полные изображения с исходным белым фоном, без обрезки и перерисовки. WebP-копии не превышают 900 × 900 px, качество 92. Для карточек направлений и статей используются существующие `direction-*.webp`, для клиентов — существующие `client-*.png`. Все ресурсы локальные.

Актуальное содержание раздела импортировано из предоставленного заказчиком `TEKST_HTML_site_FINAL_SEO_GEO_1100.zip`, полученного 6 октября 2026 года. Контакты, оборудование, доставка, оплата, акции, общие вопросы и 55 наборов требований берутся из этой версии. Сведения о возрасте компании, количестве клиентов, фиксированных ценах доставки и реквизитах из старого сайта не добавлены в новый текст.

Перенесены 150 полных статей из нового архива, включая 22 сравнительные таблицы. Темы, Title, Description и даты сверены с `SEO_ТЕКСТ_FINAL_COMPACT_GEO_1100.xlsx`, лист `07_СТАТЬИ_150`. Все 50 ранее созданных URL сохранены. Происхождение и SHA-256 исходников находятся в `company-content.json`; соответствие заголовков адресам — в `company-articles.json`.

В архиве нет галереи фотографий выполненных заказов. Страница «Примеры работ» предлагает запросить подходящий образец у студии; иллюстрации роботов обозначены как маскоты. Для новых страниц оплаты и примеров используются существующие иллюстрации компании, для акции — оригинальная иллюстрация копицентра.

Ранее скачанный `company-requisites.pdf` сохранён как существующий локальный файл, но актуальные страницы на него не ссылаются: новый архив сообщает реквизиты при подтверждении заказа.
