# ТЕКСТ — студия печати

Сайт [text-print.ru](https://text-print.ru/): 55 калькуляторов, общая корзина,
приём макетов, PDF/Excel, доставка и города, 807 статей, защищённая админка.
Основа этой версии — действующий серверный релиз от 2 ноября 2026 года.

## Локальный запуск

Нужен Node.js 24. Из корня проекта:

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:4173/. Приватные данные создаются **вне проекта**, в
соседнем каталоге `.text-admin`. Для отдельного окружения задайте `ADMIN_DATA_DIR`.
Рабочий домен задаётся только на сервере через `PUBLIC_ORIGIN`. Первичная настройка
админки: `node scripts/admin-setup.mjs`.

## Команды

| Команда                   | Назначение                                                                   |
| ------------------------- | ---------------------------------------------------------------------------- |
| `npm run check`           | Линтер, форматирование, все страницы и SEO, тесты, сборка и проверка runtime |
| `npm run lint`            | Поиск неиспользуемых переменных и функций                                    |
| `npm run format`          | Форматирование поддерживаемых JS/CSS, тестов и документации                  |
| `npm run test:regression` | Калькуляторы, корзина, документы, формы, админка и редиректы                 |
| `npm run build`           | Сборка рабочего пакета в `.build/site`                                       |
| `npm run check:runtime`   | 55 расчётов и все URL sitemap в собранном приложении                         |
| `npm run audit:unused`    | Отчёт о кандидатах на удаление CSS и изображений, без изменения файлов       |
| `npm run assets:version`  | Обновление хешей CSS/JS в HTML после изменения ресурсов; нужен Python 3      |
| `npm run build:home`      | Предварительная отрисовка главной существующим UI                            |
| `npm run prices:sync`     | Обновление примеров цен по действующим формулам                              |

GitHub Actions запускает `npm run check` при push и pull request.
Сгенерированные тарифные таблицы и сторонние библиотеки не переформатируются.

## Структура

- `.server/` — серверные модули, API, авторизация, заказы, документы и админка.
- Каталоги услуг, компании и `cities/` — готовый HTML по согласованным адресам.
- Корневые JS/CSS — общие компоненты и контроллеры разделов. Публичные пути
  сохранены, чтобы не менять адреса ресурсов на всех страницах.
- `assets/`, `fonts/`, `vendor/` — используемые изображения, шрифты и библиотеки.
- Корневые JSON и JS-модули данных — контент, тарифы и поисковые индексы.
- `scripts/` — действующие команды сборки, проверок и обслуживания.
- `tests/` — автоматические проверки и независимые тарифные снимки.
- `deploy/` — proxy, пример окружения и инструкция Docker.
- `infrastructure/indexnow/` — отдельный монитор IndexNow без рабочего ключа и состояния.
- `docs/` — архитектура и сведения об изменениях.
- `.build/`, `.work/`, `node_modules/` — локальные создаваемые файлы, исключённые из Git.

## Docker

```sh
cp deploy/.env.example .env
# Проверьте PUBLIC_ORIGIN и настройки портов.
docker compose up -d --build
```

Для work-server с существующим Nginx Proxy Manager используйте
`compose.work-server.yaml` по инструкции в `deploy/README.md`.
Заказы, макеты, доступ к админке, тарифы и настройки находятся в постоянном томе
`tekst-site_tekst_data` и переносятся отдельно от кода. Аналогично отдельно
сохраняются ключ и состояние IndexNow. Домен telegadocs.ru отключён.
