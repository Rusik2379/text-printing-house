## DNS в Jino

Пользователь вошёл в Jino. В видимой панели домена удалены две A-записи:

- `*.telegadocs.ru → 5.129.183.119`.

Остались только SOA и четыре NS. Других A, AAAA или CNAME в панели нет. NS,
регистрация домена и настройки остальных доменов не менялись. 16 прямых проверок
всех четырёх авторитетных NS для root/www и A/AAAA подтвердили отсутствие IP-адресов.
Для www ответы NXDOMAIN; у корневого имени нет адресных записей.

Старый положительный TTL — 10800 секунд: рекурсивные DNS и клиентские кеши могут
сохранять прежний адрес до 3 часов. Если конкретный браузер помнит прежний 301,
проверять в чистом окне или очищать кеш этого сайта; сервер больше не отдаёт 301.

  telegadocs.ru и www.telegadocs.ru. Это нужно, чтобы вместо сайта не показывался
  общий Default Site Nginx Proxy Manager. Не отключать эту запись, пока требуется
  закрывать запросы на прежний IP без страницы-заглушки.

- Остальные 11 proxy hosts не менялись. text-print.ru и IndexNow продолжают работать.

Восстанавливать DNS-записи или прежний 301 только по отдельной новой инструкции
пользователя. Удалённые A-записи можно воссоздать через штатную кнопку добавления
DNS-записи. Для адресного восстановления прокси используется configuration из JSON
и штатный PUT /nginx/proxy-hosts/10; полную SQLite ради одной записи не восстанавливать.
