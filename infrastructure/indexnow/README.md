# IndexNow и прямые старые URL — 26 октября 2026

По последней инструкции пользователя telegadocs.ru/www.telegadocs.ru полностью
отключены: DNS A-записи удалены, proxy host 10 закрывает HTTP без ответа, HTTPS
отклоняется. Текущее описание — `deployment-notes/TELEGADOCS-OFF-2026-10-26.md`;
ниже описана исходная установка IndexNow на основном text-print.ru.

Рабочая установка: `/opt/projects/sites/tekst-site/indexnow` на work-server.
Это отдельный Docker Compose проект `tekst-indexnow`; приложение сайта, его тексты,
метатеги, формулы, тарифы и постоянный том заказов не изменяются.

## Работа монитора

`tekst-indexnow-monitor-1` каждые 15 минут читает robots.txt и sitemap.xml основного
HTTPS-домена, затем проверяет публичные канонические страницы. Поддерживаются ETag
и HTTP 304. Сравниваются текст основного содержимого, Title/Description, изображения
и ссылки. Скрипты, стили, версии ресурсов, общий header/footer, параметры готового
расчёта и различия в пробелах не считаются содержательным обновлением.

Первый запуск только создаёт исходный снимок существующих 287 страниц: он не
отправляет их в IndexNow. Последующие запуски отправляют только изменения:

- новые страницы из актуальной карты;
- страницы с изменённым основным содержимым;
- удалённые из карты страницы, которые возвращают 404/410, редирект или noindex/другой canonical.

Удаление из одного sitemap без удаления самой страницы (HTTP 200 и прежний canonical)
не считается удалением сайта. При создании/удалении страниц необходимо поддерживать
актуальность sitemap.xml, как и до подключения IndexNow.

Состояние и очередь сохраняются в `data/state.json`, доступ 600. Поэтому перезапуск
контейнера или публикация нового приложения не приводят к повторной отправке всего
сайта. При ошибках сети, 202, 429 и 5xx очередь не подтверждается; повторные попытки
происходят с задержкой и увеличением интервала. Retry-After учитывается, один URL не
отправляется чаще чем раз в 10 минут. Ошибки Sitemap, временные 5xx, неправильный
canonical и запрет YandexBot не превращаются в массовые уведомления об удалении.

## Ключ и Яндекс

Ключ — 64 случайных шестнадцатеричных символа, `config/key.txt`, доступ 600. Nginx
Proxy Manager обслуживает корневой TXT-файл с соответствующим именем из
`/data/indexnow/` внутри контейнера NPM. Тип — text/plain, содержимое — только ключ,
без HTML. Файл не включён в Sitemap и имеет X-Robots-Tag: noindex.

Отправка: POST `https://yandex.com/indexnow`, JSON с host, key, keyLocation и urlList.
Разрешены только чистые публичные URL `https://text-print.ru`; служебные URL, заказы,
старые /uslugi/, внешние хосты и параметры калькуляторов в очередь не допускаются.

HTTP 200 подтверждает проверку ключа и приём URL. HTTP 202 означает, что новый ключ
ожидает проверки Яндекса. Для теста с 202 сохраняется отложенная автоматическая
проверка одного адреса; весь сайт ради верификации не отправляется. Принятие URL
не гарантирует индексирование или определённый срок появления в поиске.

## Команды

```sh
cd /opt/projects/sites/tekst-site/indexnow
docker compose ps
docker compose logs --tail 20 monitor
# Дополнительный проход сравнения. Неизменённые страницы не отправятся.
docker compose run --rm --no-deps monitor python monitor.py once
# Один явный тест; не повторяйте тот же URL в течение 10 минут.
docker compose run --rm --no-deps monitor python monitor.py test --url https://text-print.ru/
```

При ошибке сканирования процесс пишет её в журнал и повторяет проход через 15 минут.
`state.json` содержит время последней успешной проверки, очередь, статус проверки
ключа и последние 100 результатов отправки. Временные сетевые ошибки не завершают
рабочий цикл. Docker автоматически запускает монитор после перезагрузки сервера.

Для остановки уведомлений: `docker compose stop monitor`. Для запуска:
`docker compose up -d --build monitor`. Не удаляйте data/state.json: это история
сравнения и подтверждённых уведомлений. Ключ и состояние переносите отдельно от
публичного архива исходников. Порты хоста монитор не публикует.

## Nginx Proxy Manager

В proxy host 12 сохранены сертификат и upstream `tekst-site-app:4173`. В Advanced
добавлен блок `TEXT-INDEXNOW-20261026` с 24 точными перенаправлениями из серверного
`.server/legacy-redirects.json`. Он выполняется до нормализации протокола/хоста,
поэтому варианты HTTP, HTTPS, www, со слешем/без него и с query переходят сразу на
конечный основной URL. Query сохраняется. Неизвестные старые URL продолжают давать 404.

Стандартный флаг ssl_forced выключен только ради порядка обработки. В Advanced
после старых маршрутов и canonical www включён тот же стандартный NPM include
`conf.d/include/force-ssl.conf` с `trust_forwarded_proto F`; HTTPS принудительно
сохранён, включая защиту от подставленного X-Forwarded-Proto. Не удаляйте этот
include при ручной правке proxy host. TXT-ключ обслуживается точным location alias.

Другие 11 proxy hosts сохранены, telegadocs.ru остаётся отключённым. Если изменится
таблица старых /uslugi/ в приложении, обновите и точные правила в NPM. Другие старые
маршруты по-прежнему обслуживает само приложение.

Перед изменением сохранены, доступ 600:

- `/data/text-print-before-indexnow-2026-10-26T05-11-57-551Z.json` внутри NPM;
- `/data/before-text-print-indexnow-2026-10-26T05-11-57-551Z.sqlite` внутри NPM.

Для обычного отката proxy используйте JSON и штатный PUT `/nginx/proxy-hosts/12`.
Восстановление всей SQLite для этого не требуется. `configure-proxy.mjs` — одноразовая
установка с предохранителями; повторно запускать её поверх установленного блока нельзя.
